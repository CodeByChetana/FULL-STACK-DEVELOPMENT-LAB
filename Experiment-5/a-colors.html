Experiment 5(a) — Different Ways to Reference Colors in CSS

Explore CSS Color Formats

1. Named Color

CSS uses predefined color names.

background-color: tomato;

2. HEX Color

HEX represents colors using hexadecimal values.

background-color: #6c35de;

3. RGB Color

RGB specifies Red, Green and Blue values.

background-color: rgb(0, 150, 180);

4. RGBA Color

RGBA adds an alpha value to control transparency.

background-color: rgba(255, 70, 110, 0.75);

5. HSL Color

HSL uses Hue, Saturation and Lightness.

background-color: hsl(145, 70%, 35%);
