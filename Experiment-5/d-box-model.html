Understanding the CSS Box Model

Every HTML element is represented as a rectangular box. The CSS box model consists of content, padding, border and margin.

CONTENT
Movie Information

Gold outline = Border

Space inside border = Padding

Space outside border = Margin

1. Content: The actual text, image or other information inside an element.

2. Padding: The space between the content and the border.

3. Border: The line surrounding the content and padding.

4. Margin: The space outside the border that separates the element from other elements.
